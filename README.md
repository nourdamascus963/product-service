# Product Service

This project implements a Product Service API using Flask.
It supports full CRUD operations and includes unit tests and BDD scenarios.

## Features
- Create a product
- Read a product by ID
- Update a product
- Delete a product
- List all products
- Filter products by name, category, and availability

## Technologies Used
- Python
- Flask
- Pytest
- Behave (BDD)
